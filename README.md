# aclips.fakesign

Модуль для Bitrix24, предоставляющий тестовый провайдер подписания документов через КЭДО.

Модуль позволяет эмулировать процесс подписания документов без использования реального сервиса подписания. Это упрощает тестирование бизнес-сценариев, в которых требуется подписание документов, и позволяет проводить разработку в локальных или закрытых контурах.

## Возможности

- Эмуляция процесса подписания документов через КЭДО.
- Подмена маршрутов штатного сервиса подписания на локальный сервис модуля.
- Работа с документами в рамках штатного функционала Bitrix24.
- Предпросмотр документов:
  - через реальный сервис `sign.bitrix24.ru`;
  - через возврат заглушки без обращения к внешним сервисам.
- Поддержка локальной разработки и закрытых контуров.
- Возможность тестирования бизнес-сценариев, связанных с подписанием документов, без реального подписания.

## Принцип работы

После установки модуля происходит подмена маршрутов сервиса подписания документов на локальные маршруты модуля.

Локальный сервис доступен по адресу:

```text
https://адрес_портала/fakesign/
```

При отправке документов на подпись процесс выполняется следующим образом:

1. Пользователь инициирует штатный процесс подписания документа в Bitrix24.
2. Запросы к сервису подписания перенаправляются на локальный сервис `fakesign`.
3. Модуль эмулирует процесс подписания документа.
4. Пользователь получает результат выполнения процесса, соответствующий тестовому сценарию.

В остальном процесс взаимодействия с документами повторяет штатный функционал Bitrix24.

## Предпросмотр документов

Для работы с предпросмотром документов предусмотрены два режима.

### Через реальный сервис Bitrix24

Предпросмотр выполняется с использованием сервиса:

```text
https://sign.bitrix24.ru
```

В этом режиме для конвертации документа используется реальный сервис Bitrix24.

### Режим заглушки

Вместо обращения к внешнему сервису возвращается заглушка.

Этот режим предназначен для:

- разработки в локальном окружении;
- работы в закрытых контурах;
- тестирования без доступа к интернету;
- ускорения тестирования;
- снижения количества обращений к внешним сервисам.

## Безопасность и ограничения

Модуль предназначен исключительно для тестирования.

Документы не отправляются сторонним сервисам и не проходят реальное юридически значимое подписание.

**Исключение:** при включённом режиме конвертации через `sign.bitrix24.ru` документ передаётся реальному сервису Bitrix24 для обработки и формирования предпросмотра.

Модуль не заменяет штатный сервис подписания и не предназначен для использования в продуктивных сценариях юридически значимого документооборота.

## Установка

1. Разместить модуль в каталоге:

   ```text
   local/modules/aclips.fakesign
   ```

2. Перейти в административную панель Bitrix24:

   **Настройки → Модули → aclips.fakesign → Установить**

3. При установке модуль выполняет следующие действия:
   - создаёт необходимые таблицы;
   - создаёт настройки модуля;
   - генерирует файл подмены адреса службы;
   - копирует точку входа в каталог `/fakesign/`;
   - регистрирует правило роутинга.

   Доступность облачной службы при установке не требуется.

4. При необходимости уточнить публичный адрес тестового сервиса в настройках модуля.

## Настройки

Настройки доступны в административной панели Bitrix24:

**Настройки → Модули → aclips.fakesign**

| Поле | Опция | Назначение |
|---|---|---|
| Публичный адрес тестового сервиса | `public_base_url` | URI провайдера и генерация подмены адреса службы |
| Использовать конвертер sign.bitrix24.ru | `use_cloud_converter` | Выбор режима предпросмотра: реальный конвертер или заглушка |

Сохранение настроек сразу перезаписывает файл подмены адреса службы.

## CLI

Команды выполняются из корневого каталога Bitrix.

### Проверка состояния провайдера

```bash
php local/modules/aclips.fakesign/tools/register-provider.php status
```

Выводит:

- адрес тестового сервиса;
- endpoint службы;
- состояние файла подмены адреса.

### Просмотр журнала обращений

```bash
php local/modules/aclips.fakesign/tools/register-provider.php journal [N]
```

Показывает последние `N` записей журнала обращений к API.

Если параметр `N` не указан, используется значение по умолчанию.

### Проверка изоляции

```bash
php local/modules/aclips.fakesign/tools/check-isolation.php
```

Проверяет изоляцию тестового провайдера от облачной службы.

## Тесты

Запуск тестов выполняется из корневого каталога Bitrix:

```bash
php local/modules/aclips.fakesign/tests/run.php
```

Тесты не выполняют сетевых запросов и не обращаются к облачной службе.

## Удаление

Удаление выполняется через административную панель Bitrix24:

**Настройки → Модули → aclips.fakesign → Удалить**

При удалении модуль предлагает сохранить или удалить таблицы и настройки:

> Сохранять таблицы и настройки?

Возможны два варианта:

- **Сохранить** — таблицы и настройки остаются в системе.
- **Удалить** — таблицы и настройки удаляются вместе с модулем.

В обоих случаях выполняется удаление:

- точки входа `/fakesign/`;
- правила роутинга;
- файла подмены адреса службы (портал возвращается к использованию облачного сервиса);
- агентов модуля.
